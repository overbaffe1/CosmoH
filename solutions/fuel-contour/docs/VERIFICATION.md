## Чистый автономный пакет

`tools/package.py` сформировал ZIP с README в корне, без CosmoH/других решений, Git metadata,
venv, node_modules и браузерных бинарников. Пакет распакован в новый пустой каталог;
`bash tools/setup.sh` и `bash tools/reproduce.sh` выполнены оттуда, без Git и без зависимости
от рабочего checkout. Результат: **91 passed**, тот же summary SHA256 и exit 1 только
на известном upstream gate. Все файлы manifest, включая заново созданные результаты и HTML,
остались побайтово идентичны. Отдельно совпали все результаты Earth и Lunar.

После фиксации исходников пакет пересобирается: `source_git_revision` отражает коммит,
а SHA256 каждого файла является проверяемым описанием содержания. Сам упаковщик требует
Git checkout; обычные install/reproduce/web внутри распакованного ZIP Git не требуют.

.venv/bin/python -m fuel.cli suite --output results/repro-a
.venv/bin/python -m fuel.cli suite --output results/repro-b
diff -qr results/repro-a results/repro-b

не являются экономическим результатом. После изменения плана HTML и PDF следует пересоздать.
