# КосмоФАЙР-2 — комплект защиты

**12 слайдов, редактируемый PPTX, PDF, автономная веб-версия и отдельная речь.** Тёмные обложка/итог, светлые основные слайды, реальные изображения из train, диаграмма экспериментов и два слайда со всеми категориями 100-балльной оценки.

Это отдельный комплект по пожарам. Проект `solutions/fuel-contour` не изменён.

## Открыть

- **`КосмоФАЙР-2_защита.pptx`** — PowerPoint. Текст, карточки и диаграммы редактируются; изображениями остаются только снимок и скриншот интерфейса.
- **`КосмоФАЙР-2_защита.pdf`** — фиксированное отображение для защиты и отправки.
- **`index.html`** — открыть двойным щелчком; интернет не нужен. Стрелки / Page Up / Page Down переключают слайды, Home / End — начало и конец. Есть ссылки на PPTX/PDF.
- **`ВЫСТУПЛЕНИЕ.md` / `.txt`** — речь примерно на 4 минуты плюс ответы на вопросы. На слайды подсказки докладчику не помещены.
- **`ПРОВЕРКА_УСЛОВИЙ.md`** — подробная сверка кейса, критериев и архивной реализации, реальные проверки и риски.
- **`sources/`** — официальные постановка и критерии, с которыми сверялось содержание.

В PPTX используется **DejaVu Sans**. Для точного отображения в Windows откройте два TTF в `assets\fonts` и нажмите «Установить». Шрифты и лицензия включены. В PDF и HTML шрифты уже встроены. Нативный Microsoft PowerPoint здесь не запускался: перед защитой проверьте файл на своей машине; PDF не зависит от установленных шрифтов.

## Чего этот комплект не утверждает

- `0.7455` — скор по сообщению команды и архивному журналу, не самостоятельно проверенная карточка платформы и не итоговый private.
- 82 теста и проверка 447 строк не заменяют полный инференс, исходный шаблон и официальный замер времени.
- Default-конфигурация, `submission.csv` и `TOPsubmission.csv` не совпадают с p35. Исходный проект и веса в рамках этой работы **не исправлялись**.
- Ручная правка test запрещена; демонстрационные онлайн-слои и перенесённые контуры не являются доказательствами работы модели в регионе.
- **После стоп-кода нельзя заменять оцениваемые материалы без разрешения организатора (п. 8.5).** Этот комплект не загружен на платформу или GitVerse. Готовая презентация не означает разрешения её заменить в сдаче.

## Исходные тексты

Приложенные ранее TXT/MD не были доступны в текущей файловой среде. Поэтому создана **новая редакция по архиву и переписке**, а не заявлена точная конвертация исходника. `КосмоФАЙР-2_структура.txt` — текст именно этой новой версии. После повторного получения исходных TXT/MD можно сравнить и перенести необходимые формулировки. Подпись команды в пожарном кейсе не подтверждена — чужая команда на обложку не вставлена.

## Сборка и проверка

Генератор `build_deck.py` создаёт PowerPoint, HTML, JSON-граф слайдов и новый TXT из одной структуры. Все необходимые изображения и шрифты уже в комплекте; архив RAR для пересборки не нужен.

Windows CMD, из этой папки:

```bat
py -m pip install -r requirements-build.txt
py build_deck.py
```

После изменения HTML PDF нужно пересоздать: открыть `index.html` в Chrome/Edge, Ctrl+P → «Сохранить как PDF», включить фон и отключить колонтитулы; размер страниц задан CSS. Для программного экспорта предусмотрен `render_pdf.cjs`:

```bat
npm install
npx playwright install chromium
node render_pdf.cjs
py verify_deck.py
```

`verify_deck.py` проверяет число страниц/слайдов, редактируемость текста, отсутствие заметок докладчика, границы объектов, шрифты и контрольные факты. Это проверка презентационного комплекта, **не валидатор конкурсного решения**.

`audit-data.json`, `service-check.json`, `source-hashes.json` фиксируют выполненные проверки архива. Скрипт `audit_archive.py` повторяет структурный CSV-аудит на существующем распакованном проекте, не обучает модель и не переписывает ответы. Пример Windows CMD:

```bat
py audit_archive.py "C:\Users\Дракула\Documents\cosmo3\solutions\fires-monitoring"
```

Для сравнения с оригинальным шаблоном можно добавить `--template` и путь к имеющемуся `sample_submission.csv`. Без него совпадение ключей шаблона намеренно не считается проверенным.

## Источники и распространение

Иллюстрации train и снимок интерфейса извлечены из предоставленного командой архива. Это не сгенерированные изображения и не новые данные о пожарах. Внешние FIRMS/GIBS/GEE при создании кадра не вызывались. Данные организатора предназначены для соревнования; этот комплект не предоставляет лицензию на их свободную публикацию. Исходные CSV, веса, полный каталог, сырые TIFF и раскрытые ключи в пакет не включены.
