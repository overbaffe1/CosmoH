Положение, п. 5.2–5.3: команда — **от 3 до 5 человек**, от 14 лет; один участник может быть
только в одной команде в рамках одного хакатона. Одному участнику зарегистрироваться нельзя.

Текущий статус: участник пока один. Значит до/на старте (18.09, регистрация с 16:00) нужно
добрать **минимум 2 человека** — и это нужно сделать **в каждом городе отдельно** (Красноярск и СПб —
разные хакатоны, разные команды).

## 3. Что делать, если за 2–3 часа никого не нашли

1. Написать организаторам (чат + личные сообщения): «участник онлайн, есть готовое решение,
   ищу команду 3–5 человек» — у них есть списки одиночек и «свободных агентов», часто
   они сами сводят людей.
2. Использовать платформу: раздел поиска команды/тимирования (в СПб и Красноярске он есть).
3. Дать объявление с конкретикой (что уже сделано + какая роль нужна + сколько времени нужно человеку:
   «2–4 часа на интеграцию живых данных и демо»). Конкретика собирает людей быстрее, чем «ищу команду».
4. Заходить к командам, у которых «не хватает человека»: в чатах такие сообщения есть каждый день —
   вместо создания своей команды можно присоединиться со своим прототипом.

## 4. Быстрый онбординг пришедшего человека (5 минут)

1. Отправить ссылку на репозиторий и один файл: `README.md` решения.
2. Дать одну команду для проверки: `python -m pytest tests -q` и `uvicorn ...` → увидеть демо.
3. Показать его зону ответственности: файл и одну задачу (например, «подключить живой срез FIRMS»
   или «связать окна ВКД с витками по TLE»).
4. Предупредить про правила: п. 5.3 — только одна команда на хакатон; п. 9.5/9.6 — раскрывать
   источники; стоп-код 19.09 — после него репозиторий не трогаем.
5. Внести его в README (раздел «Команда») и в презентацию (слайд с составом) — жюри любит видеть
   понятные роли.
